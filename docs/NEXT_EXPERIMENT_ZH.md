# 第一版之后的诊断与下一步实验

本文件记录事后机制诊断和建议的第二版实验。它没有改变第一版的训练、测试或最终分数，也没有新增 LLM 生成。不能把诊断当成新方法已经提高测试成绩的证据。

## 与课程要求对齐的主线

课程 Part 1.2 要求设计新颖机器学习方法，提升指定 HypoSpace 基准上的 LLM 表现；方法自由，按创新性、重要性和完成质量评分，提交公开仓库与十分钟全员参与的小组视频。

第二版的主问题保持为：结构类别覆盖训练能否提高 LLM 在 HypoSpace 布尔任务上的合法假设覆盖？主结果沿用已披露的任务规则、共同评分口径与同预算模型生成，报告原始模型、匹配 SFT、字符串覆盖和结构覆盖的 VR/NR/RR。训练数据池变化必须同时提供给所有微调对照，评估参考集合与分母不因写法数量而改变。

梯度检查、有限语法枚举与人工写法数量不均衡实验用于解释机制；其结果不能替代常规 HypoSpace 任务的模型评估。若收益只发生在压力测试条件中，应报告为有条件的适用性，不推广成整个基准上的额外优势。仅增加写法属于数据增强；方法贡献仍需定位并检验结构分组概率与覆盖训练目标。

多训练种子、配对区间、相对 SFT 的五个百分点目标属于本项目的研究与筛选标准，并非教师规定的硬性要求。教师没有规定必须完成两个任务域或超过论文全部模型。当前两变量、深度二实验需持续标明为受控子集。实际小组视频仍需成员录制。

## 第一版留下的问题

结构类别覆盖 LoRA 相对原始模型的 RR 提升 24.09 个百分点，但相对匹配的均衡 SFT 仅提升 0.89 个百分点，按题配对区间为 [-1.97, +3.72]。相对字符串覆盖只提升 0.14 个百分点，区间为 [-4.86, +4.97]。后续需要解释独立模块为什么有用、何时有用，而不只是重复整体微调有效的结论。

## 已补做的只读梯度诊断

从每道训练题固定抽取一个类别，共 16 个训练题与类别配对；选择种子 4301，不使用验证或测试答案。在预热、SFT、结构覆盖三个已保存检查点上，分别计算 SFT 与负覆盖项的梯度。按原训练的四类别累积大小组合为四组，再统计原始梯度范数及方向。覆盖权重保持第一版的 1，不运行优化器、不修改检查点。

| 检查点 | 覆盖项/SFT 梯度范数比，四组平均 | 两个损失梯度的余弦，四组平均 |
|---|---:|---:|
| 共享预热后 | 2.66 | 0.95 |
| 均衡 SFT 最终 | 3.18 | 0.94 |
| 结构类别覆盖最终 | 2.50 | 0.86 |

运行约 201 秒。结果表明，这些采样点上的覆盖项并不弱，且与 SFT 存在明显同向成分。因此，单纯扩大权重的理由不足。它只提供机制线索：不是整个训练轨迹的测量，不等于 Adam 实际参数更新方向，也不能证明两个目标等价或模块无效。

证据：[协议](../results/diagnostics/v1_gradient_probe/protocol.json)、[逐类梯度](../results/diagnostics/v1_gradient_probe/classes.jsonl)、[批量及汇总](../results/diagnostics/v1_gradient_probe/summary.json)。脚本为 scripts/probe_coverage_gradients.py；重新运行需完整训练产生的 warmup 和两个最终检查点，或使用本地保留的第一版运行。公开的三个最终适配器不包含 warmup。脚本拒绝覆盖已有诊断记录。

## 已补做的训练类别写法审计

对两变量、AND/OR/NOT、深度至多二的固定二元语法，枚举 302 个不同表达式字符串。使用共同空间检查和规范化，只查看训练类别键，不读取测试参考集合或测试回答。

在这套有限枚举规则下，300 个字符串通过空间检查，覆盖训练中出现的 34 个参考结构类别中的 33 个。可表示类别的写法数量为 1 至 50；另一个类别没有通过检查的写法，保留上游不一致记录。第一版则对 143 个可用题目与类别配对都固定使用两个写法。

这不是全部可能文本写法的穷举，也不表示有 300 道新题。证据与完整候选池见 [v1_alias_audit.json](../results/diagnostics/v1_alias_audit.json)，可用 scripts/audit_training_aliases.py 在有原训练目标的环境中复核。

只考虑覆盖项、固定合法概率总量且允许自由分配概率的理想模型中：

- 当各类写法数量相同时，均匀分配字符串概率也能形成均匀类别概率。字符串与类别覆盖可以拥有相同的类别覆盖最优点。
- 当各类写法数量不同时，均匀分配字符串概率会给写法多的类别更多总概率；类别覆盖则直接约束类别总概率。

这为第二版提供一个可检验的问题：类别覆盖能否缓解合法写法数量不均衡造成的结构覆盖偏差？理想分布层面的结论不保证有限参数模型、有限训练或 SFT 联合目标下的优势。

## 建议的第二版最小实验

仅从训练实例构造进入参数优化的静态、校验过的类别写法池，每类最多保留四种写法；固定选择规则，并明确哪些类不足四种。验证参考仅用于评估和方案选择，验证与测试答案不进入参数优化目标。不引入 DCHG 的差异条件或推理期改写。

使用相同目标池、样本计划、基础模型与总训练预算，比较均衡 SFT、字符串覆盖和结构类别覆盖。报告每类写法数、token 曝光和实际计算成本。另做写法数量均衡的控制条件，以检验模块收益是否随不均衡程度变化。完整理想机制实验可以使用每类 [2,2,2,2] 与 [1,1,3,3] 的受控例子，但不能把人工压力测试替代常规任务结果。

先固定第一版超参数做一次匹配试跑，在验证集评估。如果存在可重复的信号，再进行至少三个独立训练种子的匹配重复。验证集用于选择方案；第一版测试结果保持不变。对已看过的 26 道题追加结果应标明是固定基准上的后续研究，不能称为全新确认性测试。确认性实验需预先冻结新的可枚举任务设置及划分，并明确任务空间变化。

## 预算和停止条件

以下是同一台 Apple M5 的估算，不是已完成实验耗时；依据第一版三个分支共约 32.5 分钟的训练循环和新池规模估计，需先用短计时试跑修正。

| 工作 | 估计时间 |
|---|---|
| 梯度及语法池诊断 | 已完成；模型探针约 3.4 分钟 |
| 四写法上限的数据池、校验及编码 | 20–40 分钟 |
| 第二版三分支匹配训练一次 | 约 60–120 分钟，以计时试跑为准 |
| 验证集比较与误差分析 | 15–30 分钟 |
| 追加训练种子及更强确认性研究 | 另约半天或更长，取决于任务空间和预算 |

优先进行约两至三小时的机制试验。若模块仍无法超过匹配 SFT 或字符串覆盖，保留负结果并缩小创新主张。只有验证集出现稳定信号时才扩大实验。新版本的成功条件应在确认性测试前固定；既报告配对区间，也检查实用提升和合法率代价。
