## 可直接讲的正文

我的方向是通过训练目标，提高模型在 HypoSpace 上的结构覆盖率。

HypoSpace 指出，模型即使生成了合法答案，也可能集中在少数假设上。我参考了 GAPO 通过组级训练学习多样性的思路，将优化重点放在模型的输出分布。

具体来说，我按基准的结构规则归并训练答案，汇总同类两种写法的概率，用十六次生成中至少命中一次的概率构造覆盖代理，再与均衡监督微调联合训练，采用 LoRA 降低训练成本。

实验在 Mac 上使用十五亿参数模型完成，设置五组对照，在二十六道测试题上使用三个推理随机种子，保持微调数据和预算一致。

恢复率从原始模型的百分之十三点七提高到三十七点八。不过，均衡微调已达到三十六点九，因此新增模块的恢复率优势仍不确定。探索性分析观察到合法率提高约三点一个百分点，同时唯一率下降。

我的贡献是任务相关的覆盖目标设计、匹配实验与可复现实现，并明确了这种优化在当前布尔子集上的收益与边界。

## 参考文献与各自作用

- [Chen et al., HypoSpace, ICML 2026](https://proceedings.mlr.press/v306/chen26bz.html)：提供问题来源和基准，说明合法生成仍可能覆盖不足。
- [Anschel et al., GAPO, EMNLP 2025](https://aclanthology.org/2025.emnlp-main.1649/)：提供组级训练可关注多样性与覆盖的相关思路；本项目没有复现或直接实现 GAPO 的强化学习算法。
- [Hu et al., LoRA](https://arxiv.org/abs/2106.09685)：提供低秩适配工具，用于降低本地训练成本；使用 LoRA 本身不是本项目创新点。
