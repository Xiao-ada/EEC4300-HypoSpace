# 个人两至三分钟讲解：结构类别覆盖 LoRA

本文件是讲解材料和录制提纲，不是已经录制的视频。按当前分工，每位组员讲自己的方法；本段只讲已经完成的第一版，第二版重训不安排执行。讲述时按实际分工说明责任，不预设谁手写了每一行代码。

## 一句话定位

我负责的是训练阶段的优化：把有限次数下的结构类别覆盖目标加入监督微调，通过 LoRA 改变模型的生成分布。

方法英文名：Canonical Coverage LoRA。创新定位是任务相关的目标设计与结构类别对齐；LoRA、概率命中公式和概率聚合本身有既有研究基础。

## 先理解这部分实际做了什么

### 研究对象

使用 HypoSpace 官方规则和生成器派生的两变量 x/y、AND/OR/NOT、深度二布尔子集。输入是部分观测，输出是符合观测与空间规则的表达式。一个观测实例可能允许多个合法结构。

示意例子：若某题有四个合法结构，十六次都生成同一个合法结构，合法率可以是 100%，但恢复率只有 25%。这是解释任务的示意，不是本项目实测结果。

### 方法的三个部分

1. 仅使用训练题参考答案，按官方 mechanistic key 分组，每类验证两种完整回答写法。`x AND y` 与 `(x AND y)` 是同一结构的两种写法；完整真值表相同不保证属于同一个官方结构类。
2. 相加同类写法的完整序列概率，用有限预算命中概率构造覆盖代理，再和均衡 SFT 联合优化。它尝试把训练目标对齐到集合覆盖，而不只训练单条回答。
3. 冻结四比特基础模型，更新 LoRA 参数。测试只输入原始观测与规则，生成结果由共同校验器评分。

公式供理解和屏幕展示，口头不逐项读符号：

```text
q_k = sum(P_theta(y | observations) for y in verified_forms_of_class_k)
C_16 = mean_k[1 - (1 - q_k)^16]
Loss = balanced_SFT_loss - C_16
```

`1-(1-q)^16` 表示十六次独立采样至少命中一次的概率；本项目 q 来自有限写法池，因此是覆盖代理，不能当成整个结构类的完整概率。

### 已经完成的实现和实验

- 基础模型：固定四比特 Qwen2.5-1.5B-Instruct，在 Apple M5、24GB Mac 上运行。
- 16 训练 / 6 验证 / 26 测试观测实例；模型仅在训练目标上更新。
- 143 个可用的“题目与类别”配对、286 条合法写法；不是 143 个不同结构类别。
- 训练 311,296 个参数；三种微调各有 200 步路径，包括 80 步共享预热与 120 步分支继续训练。
- 五种方法：原始独立采样、均衡 SFT、结构类别覆盖、字符串覆盖消融、原始模型加历史。
- 26×3×16×5=6240 次测试生成，加 480 次验证，共 6720 次正式生成。
- 三个种子是推理重复；独立训练种子只有一个。
- 已完成匹配对照、消融、原始记录导出、CPU 独立重算、数学说明、详细 README 和公开 GitHub。

## 中文主讲稿

目标约两分半；此时间是估算，未做真人实录。术语、数字和停顿会影响时长，录制前用计时器完整读一次。超过三分钟时使用下一节精简稿，不用加快到难以听懂。

我负责的方向是结构类别覆盖微调。在 HypoSpace 的两变量布尔子集中，同一组观测可能对应多个合法表达式。我的目标，是让模型在有限次生成中找到更多不同的合法结构。

方法上，我按照基准规定的结构规则归并训练答案，把同类的两种合法写法概率相加，再估计一个结构在十六次生成中至少出现一次的概率，并将这个覆盖代理加入监督微调。创新点在结构类别与有限预算训练目标的结合，LoRA 用来更新少量模型参数。

实现采用十五亿参数的开源模型，在 Mac 上完成。数据划分为十六道训练、六道验证和二十六道测试题。测试每题生成十六次，使用三个推理随机种子，共设置五组对照；三种微调使用匹配的数据和训练预算，全部输出都保留用于复核。

结果中，原始模型的恢复率约为百分之十三点七，均衡微调约三十六点九，我的方法约三十七点八。整体训练提升明显，但覆盖目标相对均衡微调只增加约零点九个百分点，置信区间跨零，尚不能确认稳定收益。探索性分析观察到合法率提高约三点一个百分点，同时结构唯一率下降。

这部分完成了任务相关的目标设计、匹配实验和可复现实现，也明确了覆盖训练的收益与局限。目前只有一个训练种子，结论限定在本次布尔子集。

## 几个术语要能用自己的话解释

| 术语 | 口头解释 |
|---|---|
| VR | 全部尝试中，满足观测和空间规则的比例 |
| NR | 不同的空间内结构数量除以尝试数；其中可能有不满足观测的结构 |
| RR | 该题参考合法结构中，被生成的不同结构所占比例，再对题目平均 |
| SFT | 用合法示例做监督微调；本项目按类别均衡抽样 |
| LoRA | 冻结原模型，只训练少量低秩参数，降低本地训练成本 |
| 结构类别 | 由基准规定的结构规范化规则决定；不能随意按完整逻辑等价合并 |
| 置信区间跨零 | 当前结果仍允许正或负的小幅差异，不能确认额外收益；不等于证明无效 |

## 可能被问到的问题

**创新是不是用了 LoRA？**

LoRA 是已有工具。项目设计点是把官方结构类聚合和有限预算覆盖代理加入训练目标，并用匹配 SFT 和去分组消融检验它。全球首创没有得到确认。

**为什么整体提升很大，仍说新增模块收益不确定？**

原始模型没有做这轮任务微调，SFT 本身就把 RR 提高到 36.86%。覆盖模型为 37.76%，两者差 0.89 个百分点的区间跨零，因此大部分整体改善不能单独归功于覆盖项。

**模块完全没有作用吗？**

设计和梯度作用可以核实。现有探索性次要推断支持合法率相对匹配 SFT 有有限改善，伴随唯一率下降；有效参考恢复率的额外优势没有确认。不是全面占优。

**为什么是十六次？**

这是事先固定的比较预算，覆盖目标也使用 N=16；各方法在相同尝试预算下比较。不是看到某个预算最好才挑出来。

**三个随机种子证明稳定了吗？**

它们只检验推理采样随机性。只有一个训练种子，不能据此声称重新训练后效果稳定。

**有没有数据泄漏？**

训练、验证、测试观测实例分开，测试参考不进入优化或提示；表达式结构家族仍可能共享，因此只主张未见观测条件上的结果。

**能说优于同组 DCHG 吗？**

目前不能直接排名，其实际模型、题目和辅助调用预算没有对齐。能说自己的路线是离线参数训练，与描述中的推理期差异条件方法不同。

**这是整个 HypoSpace 的结果吗？**

这是两变量、深度二的布尔受控子集，不是所有任务域、模型和难度的复现。
