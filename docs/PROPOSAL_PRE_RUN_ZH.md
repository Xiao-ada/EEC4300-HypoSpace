# HypoSpace 结构类别覆盖 LoRA 独立项目方案

本项目在 Apple M5、24GB 统一内存的 Mac 上完成，以 HypoSpace 布尔任务为主，训练一个同时关注合法性和假设覆盖的 LLM 适配器。工作名称为 Canonical Coverage LoRA。主方法只在训练阶段改变模型参数，测试提示只包含原始观测与任务规则。研究目标是在相同生成预算下，比均衡监督微调发现更多合法且结构不同的假设。本轮用于一天内的个人候选方法筛选，再与组员方案比较。

当前完成的是方案与实验设计。现有环境已完成 256 次旧控制器原型的真实模型调用；新增原始模型验证集基线已完成：六题、一次运行、每题十六次生成，VR=18.75%、NR=38.54%、RR=14.35%；另有四次校验通过但不属于参考枚举的输出，已单列且不计入 RR。该验证结果不是最终测试成绩。新 LoRA 损失、训练器和正式测试尚未实现或运行。旧方案保存在 CONTROLLER_PILOT_ZH.md，旧调用只作为环境与模型能力诊断，不作为本方案的效果证据。

## 与同组 DCHG 的分工边界

同组成员提供的 DCHG 描述是：根据已经找到的假设，在未观测输入上指定新的预测差异，再引导下一次生成。该描述对应推理阶段的条件探索。本方案的主方法是离线适配器训练，预测阶段固定参数和输入格式，不接收已生成答案集合，也不指定未观测位置的预测目标。

| 维度 | 同组 DCHG 描述 | 本方案 |
|---|---|---|
| 学习或搜索发生阶段 | 根据已有答案逐轮改变生成条件 | 离线训练 LoRA，测试时直接采样 |
| 主方法新增输入 | 已发现假设及希望出现的预测差异 | 无；测试仅用原始观测和规则 |
| 优化对象 | 寻找满足指定预测差异的新答案 | 将概率分给更多官方结构类别 |
| 训练更新 | 所给描述未说明参数训练 | 更新 LoRA，基础权重冻结 |
| 类别划分依据 | 指定位置上的预测差异 | 官方 mechanistic key |

本方案的核心模块不包含未观测输入选择、虚构观测约束、历史驱动差异提示、LLM 修复循环、变量置换采样或行为保持改写采样。历史提示等可作为有明确标识的共同基线，不计为本方案贡献。训练用固定括号格式变体只是概率合并的编码材料，不作为生成新候选的算法。

两条路线也可能覆盖不同的差异：本地上游校验代码确认，x 与 x AND (x OR y) 在 x/y 的四个输入上都预测 [0,0,1,1]，且都可满足观测 (0,0)->0，但官方结构键不同。这一对无法靠预测差异目标区分，结构覆盖目标则分别计数。该例说明方法区分，不证明哪种方法效果更好。

不与同组方法重复，不等于已证明相对于所有文献原创；已有覆盖和多样性训练工作仍需正常比较、引用。

## 研究问题与方法

研究问题是：加入官方假设类别的覆盖目标，能否在不明显损害合法率的情况下，提高未见观测题目的 Recovery Rate？

主要检验三个假设：覆盖方法的 RR@16 高于同预算均衡 SFT；按官方类别计算覆盖优于按字符串计算；收益能在相近 VR 下观察到。这些假设不预设为成立。

### 构造训练监督

只对训练题的观测 O，用上游生成器取得兼容参考类别 H_O。每个类别构造最多两种不同的合法完整回答写法 A_k：官方序列化表达式及为整个表达式增加冗余括号的固定格式变体。每条写法都须通过统一校验器并得到相同官方 mechanistic key，最后按完整回答 token 序列去重。

例如 x AND y 与 y AND x 属于同一类别。官方规则属于结构规范化，不能自行按德摩根律、吸收律、分配律把所有逻辑等价表达式合并。

完整回答包含 Expression 前缀及实际聊天模板的结束 token，提示和 assistant 起始标记不计入损失。训练器只能读取训练题参考标签。测试时由 LLM 自由生成，测试参考集合只用于评分。

### 合法性预热

冻结已下载的 Qwen2.5-1.5B-Instruct 四比特基础权重，只更新 LoRA 参数。先做类别均衡 SFT：均匀选题，再均匀选非空类别及该类写法，仅计算回答部分交叉熵。这样不会因为某类写法更多就给它更大训练权重。

这一步先学习格式和观测一致性，同时缓解所有合法回答概率过小时覆盖梯度过弱的问题。

### 类别覆盖损失

令 p_theta(y|O) 为完整回答 y 的序列概率，包括回答结束 token。通过回答 token 对数概率之和计算，不能使用平均 token 概率。定义：

    p_tilde[k] = sum(p_theta(y | O) for y in A_k)
    C_B = (1 / K) * sum(1 - (1 - p_tilde[k]) ** B for k in H_O)
    L = L_balanced_SFT - lambda * C_B

K 保留完整参考类别数。没有合法写法的类别贡献为零。初始 B=16、lambda=1，序列评分与推理温度均为 1。

固定分布独立采样 B 次时，若使用真实类别概率，C_B 对应期望恢复比例。有限 A_k 只覆盖部分合法写法，因此这里是这些互斥完整完成事件给出的覆盖下界。该解释要求统一停止规则和相同采样分布，不适用于动态历史提示。类别概率不重新归一化到合法候选池上。

覆盖项对高概率类别的收益逐渐饱和，为低概率类别保留训练动力；SFT 项继续提供合法答案信号。实现使用稳定的 log-sum-exp、log1p/expm1 运算，并检查概率边界、梯度及结束 token 掩码。

### 字符串消融

候选池、SFT 权重、预热及训练预算完全相同，只把覆盖项改为对每条写法分别计算：

    C_string = (1 / K) * sum(1 - (1 - p_theta(y | O)) ** B
                            for each distinct y in all A_k)

保持分母 K，使小概率区间的总体梯度尺度可比。C_string 可能超过 1，它是损失项，不是恢复比例。最终仍按官方类别评分，以检验把换写法当成新假设的影响。

## 基线结果驱动的执行重点

原始模型的六题单次验证得到 VR 18.75%、NR 38.54%、RR 14.35%。九十六次输出可分为：四十四次违反观测、三十四次未通过空间或格式检查、四次通过校验但未被参考枚举收录、七次重复参考命中、七次新增参考命中。详细分解见 results/coverage_baseline/validation/failure_breakdown.json。

三十四次检查失败中有五次对应已知 NOT/OR 与 NOR 识别问题，其中两次满足观测。这些是协议问题，不能全部归为模型错误。若修改校验或假设空间口径，必须保留当前口径记录，对原始输出和所有对照统一重新评分，不把评测修复当成模型提升；不针对某个方法单独放宽规则。

目前结果不足以声称已重现高合法率下的覆盖坍缩。最直接的模型问题是观测遵循较弱，同时参考集合内十四次命中只有七次带来新增覆盖。因此保留原有两阶段 LoRA 设计，先完成均衡 SFT 对照并检查其合法性与 RR，再评价覆盖分支。

具体执行顺序为：冻结一致评分协议；构造仅来自训练题的已验证类别均衡目标；完成共享预热和均衡 SFT 分支并验证；从相同预热参数及优化器状态继续类别覆盖与字符串覆盖分支；各分支保持预定数据和更新预算；最后运行共同固定测试。不加入 DCHG 差异条件或推理修复循环。

若均衡 SFT 在验证上没有改善，先核对标签、掩码、梯度、基础权重冻结及训练集拟合情况，不把问题归咎于覆盖损失。覆盖项的有效性以超过匹配 SFT 的 RR 为准，并检查 VR、重复率与成本。新方案的收益尚未测得。此处是对已有两阶段设计的诊断说明，不更改冻结的 plan.json、测试题目或基线采样配置。

## Mac 配置与训练预算

使用本机 GPU、MLX LM 0.32.2 和已校验的四比特模型。当前安装版支持量化 LoRA 与自定义 loss。模型与环境保留在项目根目录 runtime，公开源码不包含这些缓存。

初始配置为 rank 8、MLX scale 16、dropout 0、最后八个 transformer block 的 q_proj/v_proj、学习率 1e-4、梯度检查点、完整序列上限 1024 token。每个类别的最多两种写法组成不可拆开的概率组，通过累积形成有效回答批量 8。不得截断观测或结束 token。

先做二十步试跑，检查损失和梯度有限、适配器有更新、基础权重冻结、峰值内存和每步耗时。资源不合适时先调整批量或层数；若预计总训练超过三小时，可在正式验证和测试前统一缩减步数，并记录修订。现有实测只涉及推理，没有 LoRA 训练时长保证。

初始预算为八十步共享均衡 SFT 预热，再复制参数和优化器状态，形成三个各继续一百二十步的分支：均衡 SFT、类别覆盖、字符串覆盖。每个适配器等效接受二百步更新。分支使用同一候选组顺序和优化设置，覆盖项以外的数据曝光保持一致。采用固定最终检查点，lambda 初始固定为 1。

## 指标与结果判断

主指标是 RR@16，关键比较是类别覆盖对均衡 SFT。报告预算 1/2/4/8/10/16 下的 VR、NR、RR，以及 token、耗时和训练成本。

VR 为合法输出占全部尝试的比例。NR 为规范化后不同的空间内输出数占尝试数的比例，包含违反观测但仍在空间内的输出。RR 为找到的不同合法参考类别占完整兼容参考集合的比例。失败和重复输出都计预算。

先在每题内平均三次运行，再按题做配对 bootstrap 区间，列出全部逐题差异。二十六题仍是小实验，不能把几千条输出当成几千道独立测试题。

暂定组内采用目标为：相对均衡 SFT，RR@16 至少增加五个百分点，VR 下降不超过两个百分点。这是选择标准，不是预期收益或显著性标准。区间跨零时报告趋势不确定；只胜原始模型而未胜均衡 SFT时，覆盖目标的额外贡献未获支持。与历史基线的收益、成本也同时报告。

## 基准一致性与创新边界

现有审计发现 extended 设置有一条参考序列化表达式被同版校验器拒绝，涉及 NOR 识别。所有训练目标先校验，记录空别名类别，测试参考分母保持原样。该审计不证明相应类别在所有写法下绝对不可达。

现有 runner 还增加了解析和空间约束先通过的检查，所有方法一致使用。这是与上游整套 runner 的协议差异，绝对分数不与论文表格直接比较，测试时不使用枚举器替代模型生成。

已有 GAPO 研究组级覆盖与多样性，条件 SFT 也已有研究。拟贡献是针对官方结构类别，以有限预算覆盖下界和合法性约束训练适配器，再通过受控实验验证作用。LoRA、类别均衡与期望覆盖公式本身都不声称首次提出；均衡 SFT 本身也可能趋向均匀的类别分布；这里研究的是有限训练预算下的梯度分配和别名合并，不声称改变理想条件下的最优分布。覆盖项是否有额外价值必须由对照证明。
