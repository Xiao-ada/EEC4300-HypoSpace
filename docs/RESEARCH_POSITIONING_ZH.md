# 保留什么研究价值，哪些结论需要收缩

当前主线是研究训练目标对LLM自由生成假设覆盖的影响。方法名和漂亮分数不能替代与普通微调的匹配对照；本项目允许得到“额外收益不明确”的结果。

## 可以保留的设计

HypoSpace不是只有一个标准答案的任务。一次生成合法，并不意味着重复采样能够覆盖其他合法结构。因此，把训练单元从答案字符串调整为基准定义的结构类别，是一个可研究的设计选择。

对于训练观测O，第k类的有限合法完整回答集合为A_k，包含真实EOS。令

```text
q_k = sum_{y in A_k} P_theta(y | O)
C_N = (1/K) sum_k [1 - (1-q_k)^N]
L = balanced_SFT - C_16
```

在固定提示、独立采样和完成事件互斥等条件下，`1-(1-q_k)^N`是这些有限写法在N次中至少出现一次的概率。因为有限写法质量不超过整个类别质量，C_N给出真实期望参考覆盖的下界。测试时LLM仍从完整词表自由生成，不从A_k选择。

这个概率恒等式、LoRA和多样性训练思想都已有基础。本项目的设计价值是将它们与HypoSpace的官方mechanistic结构类别对齐，并在相同训练路径下检验是否有效，不能声称发明了新的覆盖概率定理。

## 目标为什么可能有效，也为什么可能不比SFT好

对固定合法总概率质量，覆盖函数的凹性偏好更均匀地分配到多个类别；但这里的训练同时改变合法质量与类别分布。因此RR提高不能自动解释为长尾分布变得更均匀。

对类概率q的导数为`N*(1-q)^(N-1)`，对log(q)的导数还要乘q。极低概率类别的梯度并不天然很强，有限写法池又可能遗漏大量合法表述。普通均衡SFT本身也在增加这些合法回答的概率，这些因素都可能使新增目标的独立收益很小。原有训练探针发现覆盖与SFT梯度存在明显同向成分，这也是负结果具有解释价值的原因。

主张应接受实验检验：与同数据、同更新数、同优化器状态起点的SFT相比，如果RR差的区间跨零，就说“未证实额外恢复率收益”，不以另一个更好看的指标替代预设结论。

## 当前主实验与历史实验的关系

1. **主实验：原始200步匹配检查点的自由生成。** 原始模型、Balanced SFT、Canonical Coverage、String Coverage均使用相同提示、16次预算和采样器，没有目录、修复或硬去重。
2. **历史BACE：结构约束解码补充。** 它可研究排重策略的覆盖收益与合法率代价，但唯一率保证来自规则；13/16的目标与README阈值有关，不作为模型学会多样性的证明。
3. **历史COVE：有限候选筛选补充。** 它证明学习执行器在小型候选空间内有效；执行器单独使用与LLM组合同分，不能据此宣称LLM本身达到99%或LLM因子有独立贡献。
4. **新增三变量迁移：泛化边界检查。** 冻结两变量训练得到的检查点，不适配三变量题。它检验变量数变化下的表现，既可能显示收益也可能暴露过拟合。原始RR完整保留，不通过改变预算或归一化分母追求过线。

已完成实验全部保留，不删去未胜出的偏好损失、失败的改进方向或精确符号对照。收缩主张是纠正解释，不是隐藏证据。

## 与同组方向和课程要求的关系

用户描述的DCHG是在未观测位置上指定与已知答案的预测差异，属于推理时探索。这里主要修改离线训练目标，测试时不选择未观测输入、不指定答案差异，也不使用历史条件修复。方向可以独立讲解，但在取得双方同模型、同题、同预算配置之前，不给两人的数值直接排名。

课程按novelty、importance、quality评分，没有规定必须超过README的三项参考值。可以交付一个有明确假设、有原创任务化设计、对照充分且诚实报告负结果的课程研究；这些事实不能保证具体分数，也不能代替全组视频。
