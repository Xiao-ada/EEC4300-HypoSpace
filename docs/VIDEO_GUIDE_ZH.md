# 十分钟小组视频制作指南

老师 Part 1.2 要求十分钟小组视频和公开 GitHub 仓库，每位成员参与讲解，全组同分。此文件是录制提纲，不是已经完成的视频。组员姓名与实际出镜由小组安排。

| 时长 | 内容 | 必须展示的证据 |
|---|---|---|
| 0:00–1:30 | 欠定问题与 HypoSpace：合法答案不止一个，单条正确率不能反映集合覆盖 | 一道观测题、两个合法结构；VR/NR/RR 定义 |
| 1:30–4:00 | 方法：合法监督、结构类别归并、覆盖目标和 LoRA | docs/METHOD.md 的公式及代码中的掩码、序列概率、覆盖函数 |
| 4:00–7:00 | 对照结果与成本 | results/final/test/summary.json、指标表和覆盖曲线；用实际数据替换口述数字 |
| 7:00–9:00 | 消融、逐题差异和限制 | 字符串覆盖对照、配对区间；小任务域与校验器一致性问题 |
| 9:00–10:00 | 结论、成员贡献和复现入口 | 正面与负面结果都保留；README、公开仓库和实际分工 |

各成员至少负责一个连续部分，并理解自己所讲的指标与代码。不要把程序的结构唯一率当成课程创新性评分，不声称超过论文全部模型或完成了同组 DCHG 的公平复现。

建议屏幕演示先打开 README 的最终表格，再显示某道题原始输出及 validator 结果，最后定位到 explorer/coverage_lora.py 的训练损失。需要现场生成时使用验证题并注明这是演示，不用新生成的最好例子替换正式统计。

最终上传前检查：录制总长、声音可听、每位成员参与、结果数字与导出文件一致、仓库可公开访问、没有凭据或校内账号出现在屏幕上。课程文档中的 Part 1.1 现场展示细则属于另一项考核，不自动套用为本视频的新限制。
