# 十分钟小组视频：各成员分别讲自己的方向

**当前结果入口更新：** 正式录制应以[固定预算自由生成的新结果](RESEARCH_RESULTS_ZH.md)及[新版英文两页内容](RESEARCH_PRESENTATION_EN.md)为准。下面提及的第一版和BACE讲稿保留为历史材料；现有PPTX未改成新结果，不要混用数字。当前研究不以COVE目录选择的99%作为LLM自由生成证据。

老师 Part 1.2 要求十分钟小组视频和公开 GitHub 仓库，每位成员参与讲解，全组同分，评分维度为 novelty、importance、quality。本文件按用户当前分工组织：各成员讲各自的方法，而非用十分钟全部介绍本仓库的方法。

本人的结构类别覆盖 LoRA 部分见 [中文讲解与两至三分钟稿](PERSONAL_TALK_ZH.md)、[英文备选稿](PERSONAL_TALK_EN.md)。它们是录制材料，不是已经完成的视频。成员姓名、语言和实际出镜由小组安排。

## 共同开场和个人部分

共同开场只交代 HypoSpace、多合法假设下的覆盖目标和各成员研究路线。个人部分无需重新介绍论文所有任务域，各自按“目标—方法—匹配实验—结果—边界”组织。

结构类别覆盖 LoRA 推荐两页：方法页说明官方结构分组与有限预算覆盖代理；结果页保留原始模型、均衡 SFT 和结构覆盖的核心比较，并显示消融与合法性/唯一性权衡。口头主张遵循 [CONTRIBUTION_AUDIT_ZH.md](CONTRIBUTION_AUDIT_ZH.md)，原恢复率对 SFT 的额外优势仍未证实。

## 小组比较的范围

若模型、题目、预算和评分口径一致，可以进行配对比较。若尚未对齐，结尾比较方法机制、成本和已验证结论，说明各自实验设置，不能直接将不同开发题上的平均分排序。本仓库目前没有确认同组 DCHG 的完整配置，见 [比较协议](GROUP_COMPARISON_ZH.md)。

共同结尾显示公开仓库、复现入口及各成员实际贡献。不要把本仓库三种适配器说成三位成员的方法，也不要替其他成员编造结果或贡献。

## 录制与提交核对

- 每位成员至少负责一段连续讲解，并理解所讲目标和指标。
- 总长按老师十分钟要求安排，声音清晰、公式可读、结果数字与原始导出一致。
- 明确本方法是两变量、深度二布尔受控子集；三个推理种子不等于三次独立训练。
- 结构唯一率 NR 与课程创新性不同；整体微调收益不全部归因于覆盖项。
- Part 1.1 的现场“七分钟展示、两分钟演示、一分钟代码”和无稿细则属于另一项考核，未在 Part 1.2 中重复规定。
- GitHub 保持公开可访问，屏幕录制不出现凭据或校内账户信息。

实际录制、成员出镜和最终视频文件仍需小组完成。讲稿及提纲不能替代视频。
