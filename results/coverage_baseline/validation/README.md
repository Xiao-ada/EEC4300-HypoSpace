# 原始模型验证集基线结果

固定的未微调 Qwen2.5-1.5B-Instruct 四比特模型，在六道验证题上各独立生成十六次，共九十六次，运行编号 101。模型使用原始观测与规则、空历史提示；没有加载 LoRA、修复或差异目标。温度 1，完整采样设置和版本哈希在 config.json。

| 生成预算 | VR | NR | RR |
|---|---:|---:|---:|
| 每题十次 | 20.00% | 41.67% | 9.72% |
| 每题十六次 | 18.75% | 38.54% | 14.35% |

结果为按题平均。NR 是空间内规范化唯一率，包含不符合观测的答案，并非课程创新性分数。只有六题、一次随机运行，不提供确定性泛化或方法优胜结论，也不能与其他题目或模型的分数直接排名。最终二十六道测试题尚未生成。

原始生成中十八次通过校验。四次校验通过的输出对应一个不在参考枚举中的结构键，完整表达式及所属题目记在 verification.json；它们不计入 RR，原参考分母不变。这是已披露的生成器与校验器一致性问题，各方法必须使用同一规则比较。

模型调用累计报告 52286 token、约 32.23 秒推理时间，不包括安装、代码实现、模型校验及分析时间。无请求错误，所有九十六条输出已重新解析、评分，并与逐题汇总及调用账本对账。

- summary.json：汇总及预算前缀。
- per_task.json：逐题参考数量、命中数和指标。
- evidence.jsonl：每次原始回答、提示、观测、采样种子、用量和评分；未包含账户或参考答案输入。
- verification.json：复核结果、私有原始日志哈希及参考集合差异。
- config.json：固定模型、采样、源码和划分的版本信息。
- curves.csv 与 coverage.svg：完整预算曲线。

复现：先启动 scripts/local_mlx.py 的无适配器本地服务，然后在仓库根目录运行 `.venv/bin/python -m explorer.baseline --split validation --method base_iid`。现有运行会断点恢复。此命令只获得原始模型基线，不训练新方法。

失败分解见 failure_breakdown.json：44 次违反观测，34 次未过空间/格式检查，4 次校验通过但参考未收录，7 次重复参考命中，7 次新增参考命中。34 次检查失败中有 5 次涉及已知 NOR 识别形态，其中 2 次符合观测；这不是新模型成绩，也未修正当前基线分数。
